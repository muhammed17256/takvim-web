Teknolojiler

Saf HTML, CSS ve JavaScript. Etkinlikler tarayıcının localStorage alanında saklanır, sunucuya veri gitmez. Sayfalar nginx ile servis edilir ve Docker image'ı olarak paketlenir.

Docker komutları

KULLANICI_ADI yerine Docker Hub kullanıcı adını yaz.

docker build -t KULLANICI_ADI/takvim-web:v1.0 --build-arg APP_VERSION=v1.0 .
docker run -d -p 8080:80 --name takvim KULLANICI_ADI/takvim-web:v1.0
docker login
docker push KULLANICI_ADI/takvim-web:v1.0
docker pull KULLANICI_ADI/takvim-web:v1.0
